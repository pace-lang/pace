## What is Pace?

**Pace** is a modern, statically typed, natively compiled programming language designed from the ground up to be intuitive, safe, and blazingly fast. It stands entirely on its own, offering a unique blend of high-performance execution and developer-first ergonomics. 

At its core, Pace is built on three pillars:

1. **Safety**: Strict, compiler-enforced null safety (`T?`) prevents entire classes of runtime errors. You'll never see a `NullPointerException` again.
2. **Predictable Performance**: Pace uses deterministic Automatic Reference Counting (ARC) instead of a tracing garbage collector. This guarantees memory safety without unpredictable pause times.
3. **Expressiveness**: First-class support for both Object-Oriented (Classes, Interfaces) and Functional (Algebraic Data Types, Pattern Matching) paradigms.

## v0.1.0 Feature Highlights

We have successfully built a fully functioning compiler suite from scratch! Here is what you can do in Pace today:

### 🧱 Object-Oriented & Functional Design

Pace embraces multi-paradigm programming. You can define robust contracts using `interface` and `class`, while also taking advantage of powerful Algebraic Data Types (ADTs).

Getting started is as simple as this:

```pace title="Hello World"
func main() {
    print("✨ Welcome to Pace — let's make something great.");
}
```

### 🧠 Modern Memory Management (ARC)

Pace uses Automatic Reference Counting (ARC). Objects are automatically retained and released by the compiler. You don't have to write manual memory management code, and there's no background garbage collector slowing down your application.

```pace title="Zero-Pause ARC"
class DataBuffer {
    init() { print("Buffer Created") }
}

func process() {
    // Memory is allocated. Reference count = 1
    let buffer = DataBuffer() 
    
} // buffer goes out of scope. Reference count = 0. Memory is instantly freed!
```

We've also built in `weak` references to safely break reference cycles without leaking memory!

### 🛡️ Iron-Clad Safety

- **Strict Null Safety**: Pace forces you to handle missing data explicitly at compile time. 
- **Native Arrays**: Dynamically sized arrays with strict bounds checking and highly optimized, contiguous memory layouts.

## Under the Hood: A Modern Architecture

For the compiler enthusiasts out there, the Pace compiler is a multi-pass architecture built in Rust. It takes your code through a rigorous journey:

1. **Frontend**: A fast, recursive descent parser building a strictly typed Abstract Syntax Tree (AST).
2. **Semantic Analysis**: Advanced name resolution, scope tracking, and a robust Typechecker.
3. **MIR Lowering**: Lowers the AST into a Mid-level Intermediate Representation (MIR) that explicitly models control flow and memory (ARC) operations.
4. **Backend (Codegen)**: Translates MIR directly into highly optimized native machine code using the **Cranelift** backend.

> [!NOTE]
> Our Diagnostics Engine provides beautiful, structured error reporting with precise source spans, ensuring that when things go wrong, the compiler acts as a helpful pair programmer rather than an adversary.
