Ready to write your first line of Pace? Follow this guide to get the compiler running on your machine.

## Install Pace Toolchain

Pace is distributed as a prebuilt native toolchain. **You do not need Rust or Cargo to use Pace.**

### Linux / macOS

```bash title="Terminal"
curl -fsSL https://raw.githubusercontent.com/pace-lang/pace/main/installer/install.sh | bash
```

### Windows (PowerShell)

```powershell title="PowerShell"
irm https://raw.githubusercontent.com/pace-lang/pace/main/installer/install.ps1 | iex
```

### Verify Installation

Open a new terminal and run:

```bash title="Terminal"
pace --version
```

## Hello, World!

Let's write your first Pace program. Create a new file called `hello.pace`.

```pace title="hello.pace"
func main() {
    print("Hello, World!");
}
```

Now, compile and run the file using the Pace CLI:

```bash title="Terminal"
pace run hello.pace
```

**Output:**

```text title="Terminal"
Hello, World!
```

Congratulations! You've successfully installed Pace and executed native machine code. 

While running a single file is great for small scripts, real applications require multiple files and dependencies. In the next section, we'll explore **Pace's built-in tooling and project management**.

## Building from source (Contributors)

If you are a contributor working on the Pace compiler itself, you will need to build from source using Rust and Cargo.

1. Install Rust via [rustup](https://rustup.rs/):

   ```bash title="Terminal"
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```

2. Clone and build the repository:

   ```bash title="Terminal"
   git clone https://github.com/pace-lang/pace.git
   cd pace
   cargo build --release
   ```
