Ready to write your first line of Pace? Follow this guide to get the compiler running on your machine.

## Prerequisites

Currently, Pace is built from source. You will need to install **Rust** to compile the Pace toolchain.

1. Install Rust via [rustup](https://rustup.rs/):

   ```bash title="Terminal"
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```

2. Verify you have version `1.97.1` or later:

   ```bash title="Terminal"
   cargo --version
   ```

## Installing the Compiler

1. Clone the Pace repository:

   ```bash title="Terminal"
   git clone https://github.com/pace-lang/pace.git
   cd pace
   ```

2. Build the workspace using Cargo:

   ```bash title="Terminal"
   cargo build --release
   ```

3. The Pace compiler binary will be available at `target/release/pace`. You can alias it or add it to your PATH for convenience:

   ```bash title="Terminal"
   export PATH=$PATH:$(pwd)/target/release
   ```

## Hello, World!

Let's write your first Pace program. Create a new file called `hello.pace`.

```pace title="hello.pace"
func main() {
    print("Hello, World!");
}
```

Now, compile and run the file using the Pace CLI:

```bash title="Terminal"
pace run hello.pace
```

**Output:**

```text title="Terminal"
Hello, World!
```

Congratulations! You've successfully installed Pace and executed native machine code. 

While running a single file is great for small scripts, real applications require multiple files and dependencies. In the next section, we'll explore **Pace's built-in tooling and project management**.
